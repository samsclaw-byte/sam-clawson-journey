### Embedded Chat Interface Concept
User proposed chat widget on each page for natural language entry:

**Concept:** Floating chat where users type "I drank 2 glasses" or "Add task: Call John"

**Two Implementation Options:**
1. Telegram WebApp (easiest) - iframe embed, Telegram auth, routes to bot
2. Custom WebSocket (more control) - Cloudflare Worker, JWT auth, command validation

**Security Requirements:**
- Command whitelist (add_, query_, help only)
- Block admin/config/system commands
- Rate limiting (10/min, 100/day per user)
- Context isolation (user_id verification)

**Cost Implications:**
- 1 user: ~$5/mo
- 10 users: ~$50/mo  
- 50 users: ~$250/mo
- Mitigation: Local LLM for simple commands
