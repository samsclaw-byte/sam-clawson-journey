📋 Workflow Overview

Automated daily security audits checking SSH configuration, system updates, file permissions, and potential vulnerabilities.

1

Daily Scan

Cron job runs security audit script checking: SSH config, UFW status, file permissions, system updates, sensitive file exposure.

2

Analysis

Results analyzed against security baselines. Issues categorized by severity (critical, warning, info).

3

Reporting

Security report generated and sent via Telegram. Critical issues trigger immediate alerts.

🔧 Technical Details

  • Schedule: Daily at 2:00 AM
  • Checks: SSH, UFW, permissions, updates
  • Delivery: Telegram notification
  • Log: ~/.openclaw/security_audit.log
