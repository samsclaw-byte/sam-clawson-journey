🌅 Morning Brief Workflow

Daily automated health and productivity summary

← Back to Architecture Mission Control

📋 Workflow Overview

The Morning Brief delivers a comprehensive daily summary combining health metrics, productivity stats, and prioritized tasks to start your day informed and focused.

1

5:50 AM - WHOOP Token Health Check

Cron job verifies WHOOP API token validity. If expired, attempts automatic refresh using refresh token.

2

6:00 AM - Data Aggregation

Collects data from multiple sources: WHOOP (recovery, sleep), Airtable (habits, food log), TAT system (tasks), Calendar (events).

3

AI Analysis (Kimi)

Aggregated data sent to Kimi AI for intelligent analysis: recovery-based workout suggestions, task prioritization, nutrition insights.

4

Summary Generation

Formatted briefing created with sections: Recovery Score, Sleep Analysis, Today's Priorities, Water/Habit Status, Upcoming Events.

5

Delivery

Brief sent via Telegram with actionable insights and recommendations for the day.

🔧 Technical Details

  • Schedule: Daily at 6:00 AM (Asia/Dubai timezone)
  • Cron Expression: 0 6 * * *
  • Data Sources: WHOOP API, Airtable, TAT Database, Calendar API
  • AI Model: Kimi K2.5
  • Delivery: Telegram Bot API
  • Fallback: If WHOOP API fails, uses last known data
