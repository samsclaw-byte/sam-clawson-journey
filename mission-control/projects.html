💬 Embedded Chat Interface

Allow users to chat with AI directly from dashboard pages

Concept Overview

Floating chat widget on each page (Health, Work, etc.) where users type natural language like "I drank 2 glasses of water" or "Add task: Call John tomorrow"

✓ Pros

  • No app switching (Telegram → Web)
  • Context-aware (on Health page = health context)
  • Familiar interface
  • Mobile-friendly
  • Can guide users with prompts

✗ Challenges

  • Security: Sandbox user inputs
  • Cost: Rate limiting per user
  • Permissions: User vs Admin commands
  • Auth: Verify user before processing
  • Scope: Prevent "change password" etc
🔧 Technical Approach:
WebSocket → Telegram Bot → OpenClaw → Filtered Response
Only allow: add_[habit|task|food|water], query_[data], help
Block: config_*, delete_*, system_*, admin_*

✨ Key Features

  • 📱

⚠️ Key Risks

  • Security: User isolation failures, data leaks between accounts
  • Costs: AI API usage scales with users (need rate limits)
  • Complexity: More features = more bugs, harder maintenance
  • Support: Family/friends need help, you're the only dev
  • Lock-in: Once people depend on it, hard to change stack
