Active Data Flows

  • 💬 Telegram → 🦞 OpenClaw → 🗄️ Airtable (Food Log)
  • 💓 WHOOP → 🌐 Webhook → 🗄️ Airtable (Recovery)
  • 📅 Google Calendar → ⏰ Cron → 📱 Mission Control
  • 🥗 Food Text → 🔬 Edamam → 🗄️ Nutrition Data

Cron Schedule

  • 1am-5am: Overnight Build/Research Tasks
  • 5:50am: WHOOP Token Health Check
  • 6:00am: Morning Brief, Security Audit
  • 10am-8pm: Water Reminders
  • Every 15min: Dashboard Refresh

Key Integrations

  • Moonshot AI (Kimi K2.5): Main reasoning engine
  • Airtable: Health data, habits, TAT tasks
  • GitHub: Code storage, sync, versioning
  • Cloudflare: Tunnels (SSH, WHOOP), Workers
  • Google Calendar: Family schedule via Maton API
